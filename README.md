# Автотесты для сайта размещения объявлений

## Описание

Проект представляет собой набор автоматических тестов на Python с использованием библиотеки Selenium для тестирования функциональности сайта: https://qa-desk.stand.praktikum-services.ru/.

Тесты охватывают следующие сценарии:
- Регистрация пользователя
- Авторизация (Login)
- Выход из аккаунта (Logout)
- Создание объявления
- Ограничения для гостей

## Структура проекта

```
Sprint_5/
├── conftest.py                 # Фикстуры для запуска тестов
├── requirements.txt            # Зависимости проекта
├── .gitignore                  # Исключения для git
├── README.md                   # Описание проекта
├── tests/
│   ├── test_login.py
│   ├── test_logout.py
│   ├── test_registration.py
│   ├── test_registration_invalid_email.py

│   ├── test_create_ad_authorized.py

```

## Требования

- Python 3.10+
- Google Chrome
- ChromeDriver соответствующей версии

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```

## Особенности

- Инстанс драйвера создается и закрывается через фикстуру `driver` в `conftest.py`.
- Все тесты независимы и не содержат `sleep`, `print` или условных конструкций.
- Генерация уникального email осуществляется для каждого теста регистрации.
- Все проверки заканчиваются `assert`.

## Поддерживаемые функции

- [x] Регистрация с валидными и невалидными email
- [x] Авторизация и выход из аккаунта
- [x] Размещение объявления от авторизованного пользователя
- [x] Проверка ограничений для неавторизованных пользователей
